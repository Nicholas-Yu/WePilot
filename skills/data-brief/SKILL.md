# Data Brief

Use this skill when the user wants a business/data brief, a weekly/monthly report, a campaign review, a channel review, or a management-facing summary.

Produce an analyst-style brief:

- Start with the answer, not background.
- Preserve exact metrics and named entities.
- Explain what changed, why it matters, and what to do next.
- Distinguish observation, diagnosis, and recommendation.
- Avoid generic praise. Be concrete.

Default output structure:

- 结论先行
- 数据证据
- 变化与归因
- 问题/风险
- 建议动作
- 需要补充的数据或验证
