# Presentation Analysis

Use this skill for PowerPoint decks.

Analyze the deck as a presentation, not just text:

1. Reconstruct the storyline.
2. Summarize each important slide or section.
3. Identify slide-level claims, evidence, metrics, and missing support.
4. Highlight weak logic, repeated pages, unclear transitions, or overloaded slides.
5. If asked, produce speaker notes or an executive briefing.

Default output structure:

- 整体叙事
- 逐页/分章节摘要
- 关键数据和论据
- 逻辑风险或缺口
- 汇报建议
- 可复用话术
